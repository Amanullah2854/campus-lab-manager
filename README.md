# Campus Lab Manager 🖥️⚡

A modern web application for managing college computer laboratories, including computers, students, lab sessions, and equipment maintenance.

## ✨ Features

- 📊 Dashboard with laboratory statistics and recent activity
- 🖥️ Computer Management
  - Add, edit, and delete computers
  - Track computer availability
  - Search and filter computers
- 👨‍🎓 Student Management
  - Add, edit, and delete students
  - Search student records
  - Student information management
- 📅 Lab Session Management
  - Schedule lab sessions
  - Edit and delete sessions
  - Search and filter sessions
  - Manage class, lab, instructor, date, and time
- 🔧 Maintenance Management
  - Report computer issues
  - Track maintenance status
  - Set issue priority
  - Mark issues as resolved
  - Search and filter maintenance records
- ✅ Form validation and confirmation dialogs
- 🔔 User feedback and notifications
- 📱 Responsive design for desktop, tablet, and mobile

## 🛠️ Technology Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Lucide React
